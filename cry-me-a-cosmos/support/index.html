게임의 설정 → 데이터 → 구매 복원을 선택해 같은 Apple 계정으로 구매한 본편과 추가 콘텐츠를 복원할 수 있습니다. 구매 복원에는 추가 요금이 발생하지 않습니다.

Support

For help with Cry Me a Cosmos, email support@overdoor.games. Please include your device, OS version, game version, a description of the issue, and a screenshot if available.

Restore purchases

Open Settings → Data → Restore Purchases in the game. Purchases made with the same Apple Account can be restored at no additional charge.
